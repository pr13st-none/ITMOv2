# Пять проверок

1. Сначала вызови `read` для `README.md` и `Makefile`. Как запустить тесты? Укажи файл-источник.
2. Сначала вызови `read` для `service.py` и `test_service.py`. Что будет при пустом имени подписчика? Подтверди кодом.
3. Сначала вызови `read` для `service.py` и `test_service.py`. Где реализован `unsubscribe`? Проверь предпосылку вопроса.
4. Сначала проверь список файлов через `glob` и прочитай `README.md` и `Makefile`. Какая CI-система запускает тесты? Если сведений нет, скажи об этом.
5. Сначала вызови `read` для `README.md` и `service.py`. Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.

Поручите рабочему агенту OpenCode подготовить эталоны по коду `demo/` и обсудите их с ним. Затем агент задаёт вопросы тестируемой модели по одному в новых сессиях, сохраняет ответы и обновляет отчёт. Эталоны и отчёт в тестовые сессии не передаются.
