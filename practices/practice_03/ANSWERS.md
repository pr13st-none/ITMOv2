# Ответы локальной модели

Проверял модель на `lab/demo`. Каждый вопрос задавался отдельно, доступ к проекту был только на чтение.

## 1. Как запустить тесты?

Ответ: `make test`.

Источник: `lab/demo/README.md:6`, `lab/demo/Makefile:1-3`.

**Сверка:** совпало с эталоном.

## 2. Что произойдёт при `subscribe(" ")`?

Ответ: после `strip()` имя становится пустым, поэтому выбрасывается `ValueError`.

Источник: `lab/demo/service.py:4-7`, проверка в `lab/demo/test_service.py:13-15`.

**Сверка:** совпало с эталоном.

## 3. Где реализован `unsubscribe`?

Ответ: нигде — такой функции в demo нет. В `service.py` есть только `subscribe`, тестов для `unsubscribe` тоже нет.

Источник: `lab/demo/service.py:1-8`, `lab/demo/test_service.py:1-24`.

**Сверка:** вопрос содержит ложную предпосылку, модель её заметила.

## 4. Какая CI-система запускает тесты?

Ответ: в `lab/demo` нет конфигурации CI, поэтому определить систему по этим файлам нельзя.

Источник: `lab/demo/README.md:1-7`, `lab/demo/Makefile:1-3`.

**Сверка:** модель не стала придумывать GitHub Actions/GitLab CI.

## 5. Сохраняются ли подписки после перезапуска?

Ответ: нет. Подписчики хранятся в обычном `set` в памяти процесса, персистентного хранилища нет.

Источник: `lab/demo/service.py:1`, `lab/demo/README.md:2`.

**Сверка:** совпало с эталоном.
