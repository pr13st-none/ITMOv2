**Эталон рабочего агента:** В доступном demo нет сведений о CI; README.md:1-8 и Makefile:1-6 не содержат CI-конфигурации

**A:** CI-система, которая запускает тесты проекта, не указана прямо в файле Makefile. Однако, в Makefile есть цель `test`, которая запускает тесты с помощью `unittest` Python. Конфигурационный файл для CI-системы, вероятно, отсутствует в предоставленных файлах. Источник: Makefile.

Сверка: B корректно сообщает, что данных нет. A тоже не назвал CI, но добавил ненужное «вероятно». `Makefile` — runner, не доказательство существования CI; сведения отсутствуют в доступном demo.

## Q5. Сначала вызови read для README.md и service.py. Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.

**Эталон рабочего агента:** Нет: subscribers — обычный set в памяти процесса; README.md:3, service.py:1

**A:** Подписки не сохраняются после перезапуска процесса, так как данные хранятся в памяти процесса (см. README.md). В коде `service.py` используется множество `subscribers`, которое обнуляется при перезапуске. Источник: README.md.

**B:** Подписки не сохраняются после перезапуска процесса, так как они хранятся в памяти процесса (строка 3 из README.md). В коде `service.py` подписчики хранятся в переменной `subscribers`, которая является объектом `set` и существует только в текущем процессе.

Сверка: Основной факт верен у обоих. B указал `README.md:3`, но ссылка на код у обоих без номера строки: `service.py:1`.
