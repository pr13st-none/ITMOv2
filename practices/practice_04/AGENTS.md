# Правила для агента

Перед изменениями прочитай этот файл и `SKILL_ANALYSIS.md`.

- Полная проверка проекта: `bash check.sh`.
- Для изменений поведения сначала добавляй тест, который падает, затем делай минимальную правку.
- Не ослабляй валидацию ради прохождения тестов.
- `review_contract.py` — единственный источник правил проверки payload; MCP должен использовать ту же функцию.
- После изменения Python-файлов или тестов обязательно дождись результата hook-а.
