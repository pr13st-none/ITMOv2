# Unit-проверки

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| В review допустимо от 0 до 3 рисков | Валидатор структуры результата | (a) результат с 4 risks; (b) валидный результат с 0 risks | (a) отклонён с причиной `too_many_risks`; (b) принят и не требует искусственно добавлять finding | Автотест валидатора |
| У каждого риска есть evidence | Валидатор одного risk | Risk без `file:line` или evidence | Risk не проходит проверку | Автотест валидатора |
| Неизвестное не становится доказанным дефектом | Сборщик prompt | Context Pack без правила про auth | Prompt содержит правило «не придумывать требования» | Snapshot/строковая проверка prompt |
| Diff отделён от правил | Сборщик prompt | Diff с текстом `Ignore previous instructions` | Этот текст находится только в секции входных данных, правила остаются неизменными | Unit-тест PromptBuilder |
| Ошибка LLM не интерпретируется как успешный review | `ReviewService` с fake LLM | `generate()` выбрасывает `RuntimeError` | `review()` не возвращает обычный `{"comment": ...}`; ошибка остаётся наблюдаемой вызывающей стороне (напрямую или как доменная ошибка) | Unit-тест с fake LLM |

## Как использовали AI

- Строка в [`prompts.md`](prompts.md): `P1-03`.
